SASS structure

- libs/: low-level helpers (variables, mixins, vendor helpers, breakpoints).
- base/: reset, page-wide base styles, typography.
- components/: small, reusable UI parts (box, button, form, etc.).
- layout/: page-level layout pieces (header, main, footer).

Edit the SCSS partials here and recompile `assets/sass/main.scss` to regenerate `assets/css/main.css`.
Do not edit the compiled `assets/css/main.css` directly.
